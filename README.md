# Arena

Papan skor pertandingan untuk futsal, sepak bola, basket, dan bulu tangkis. Angka besar, tombol besar, dan waktu pertandingan di tengah layar, supaya skor mudah dibaca dari kejauhan.

Setiap cabang punya aturan dan lapangan sendiri. Futsal memakai dua babak 20 menit, sepak bola dua babak 45 menit, basket empat kuarter 10 menit, dan bulu tangkis sampai 21 poin dengan selisih dua. Nama tim, warna, dan sisi bisa diganti kapan saja. Skor yang salah bisa diurungkan, lalu pertandingan bisa direset kalau ingin mulai dari nol.

## Menjalankan

Buka `index.html` di browser, atau jalankan server lokal dari folder ini:

```bash
php -S localhost:5501 -t .
```

Lalu buka [http://localhost:5501](http://localhost:5501).

Skor terakhir disimpan di browser.
