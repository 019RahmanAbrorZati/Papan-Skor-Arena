# Arena

Papan skor pertandingan untuk futsal, sepak bola, basket, dan bulu tangkis. Angka besar, tombol besar, dan waktu pertandingan di tengah layar.

## Menjalankan

Buka `index.html` di browser, atau:

```bash
php -S localhost:5501 -t .
```

Lalu buka [http://localhost:5501](http://localhost:5501).

Skor terakhir disimpan di browser.
